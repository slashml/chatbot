# Groups API

The Groups API provides endpoints for retrieving user information and statistics.

## Get User by ID

Retrieve detailed information about a specific user including their posts and accounts.

### Endpoint

```
GET /api/groups/[id]
```

### Parameters

| Parameter | Type   | Required | Description           |
|-----------|--------|----------|-----------------------|
| id        | string | Yes      | The unique user ID    |

### Response

Returns a user object with related data:

```json
{
  "id": "user_123",
  "name": "John Doe",
  "email": "john@example.com",
  "posts": [
    {
      "id": "post_1",
      "title": "Example Post",
      "content": "Post content..."
    }
  ],
  "accounts": [
    {
      "id": "account_1",
      "provider": "google",
      "providerAccountId": "123456"
    }
  ]
}
```

### Error Responses

| Status Code | Description          |
|-------------|----------------------|
| 404         | User not found       |
| 500         | Internal server error|

### Example Request

```bash
curl https://your-domain.com/api/groups/user_123
```

## Get User Statistics

Retrieve aggregated statistics about users in the system. This endpoint requires authentication.

### Endpoint

```
GET /api/groups/stats
```

### Authentication

This endpoint requires a valid session. Include authentication credentials in your request.

### Response

Returns statistics about the user base:

```json
{
  "totalUsers": 1250,
  "activeUsers": 342,
  "recentUsers": 45,
  "timestamp": "2025-10-18T23:41:02.715Z"
}
```

### Response Fields

| Field        | Type   | Description                                    |
|--------------|--------|------------------------------------------------|
| totalUsers   | number | Total number of registered users               |
| activeUsers  | number | Number of users with active sessions           |
| recentUsers  | number | Number of users registered in the last 7 days  |
| timestamp    | string | ISO 8601 timestamp of when stats were generated|

### Error Responses

| Status Code | Description                           |
|-------------|---------------------------------------|
| 401         | Unauthorized (no valid session)       |
| 500         | Failed to fetch statistics            |

### Example Request

```bash
curl -X GET https://your-domain.com/api/groups/stats \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Notes

- The `/api/groups/[id]` endpoint returns user data with nested relationships (posts and accounts)
- The `/api/groups/stats` endpoint requires authentication to prevent unauthorized access to user metrics
- Statistics are calculated in real-time based on database queries
- Active users are determined by session expiration dates
- Recent users include those registered within the last 7 days
