# Welcome to Chatbot

Chatbot is a modern, AI-powered application built with **Next.js 15+** that combines Google’s Gemini AI with Google OAuth authentication. It offers a rich real-time chat experience, an extensible API, and a growing SDK for programmatic access.

## Features

- **AI-Powered Conversations** – Integrates Google Gemini for natural language responses
- **Real-time Chat Interface**
- **Google OAuth Authentication** with **NextAuth.js**
- **Admin Dashboard** for managing users and groups
- **User & Usage Statistics** endpoints
- **Dark-Mode Toggle** for theme switching
- **Local Storage** persistence of chat history
- **Responsive Design** (desktop & mobile)
- **Next.js 15+ App Router**
- **TypeScript First** codebase & SDK

## Project Structure

```bash
app/
├── admin/              # Admin dashboard
├── api/                # API routes
│   ├── auth/           # Authentication endpoints
│   ├── chat/           # Chat endpoints
│   ├── users/          # User management endpoints
│   ├── blog/           # Blog endpoints
│   ├── group/          # Group endpoints
│   ├── orgs/           # Organization endpoints
│   └── teams/          # Team endpoints
├── components/         # Reusable UI components (ChatInterfaceComponent, DarkModeToggle…)
├── [static pages]/     # e.g., about/, help/, contact/, privacy-policy/
├── profile/            # User profile pages
├── settings/           # User settings
└── sdk/                # TypeScript SDK for external integrations
```
