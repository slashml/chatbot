# Teams API

The Teams API provides endpoints for retrieving user details and team statistics.

## Get User by ID

Retrieve detailed information about a specific user, including their posts and accounts.

### Endpoint

```
GET /api/teams/{id}
```

### Parameters

| Parameter | Type   | Required | Description           |
|-----------|--------|----------|-----------------------|
| id        | string | Yes      | The unique user ID    |

### Response

Returns a user object with the following structure:

```json
{
  "id": "string",
  "name": "string",
  "email": "string",
  "posts": [
    {
      "id": "string",
      "title": "string",
      "content": "string"
    }
  ],
  "accounts": [
    {
      "id": "string",
      "provider": "string"
    }
  ]
}
```

### Status Codes

- `200` - Success: User found and returned
- `404` - Not Found: User with the specified ID does not exist
- `500` - Internal Server Error: An error occurred while fetching the user

### Example Request

```bash
curl -X GET https://your-domain.com/api/teams/user_123 \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Example Response

```json
{
  "id": "user_123",
  "name": "John Doe",
  "email": "john@example.com",
  "posts": [
    {
      "id": "post_456",
      "title": "My First Post",
      "content": "Hello world!"
    }
  ],
  "accounts": [
    {
      "id": "account_789",
      "provider": "google"
    }
  ]
}
```

## Get Team Statistics

Retrieve statistics about users and team activity. This endpoint requires authentication.

### Endpoint

```
GET /api/teams/stats
```

### Authentication Required

This endpoint requires a valid session. Include your authentication token in the request.

### Response

Returns team statistics with the following structure:

```json
{
  "totalUsers": 150,
  "activeUsers": 45,
  "recentUsers": 12,
  "timestamp": "2023-10-16T10:30:00.000Z"
}
```

### Response Fields

| Field        | Type   | Description                                    |
|--------------|--------|------------------------------------------------|
| totalUsers   | number | Total number of users in the system            |
| activeUsers  | number | Number of users with active sessions           |
| recentUsers  | number | Number of users created in the last 7 days     |
| timestamp    | string | ISO 8601 timestamp of when stats were generated|

### Status Codes

- `200` - Success: Statistics returned successfully
- `401` - Unauthorized: No valid session found
- `500` - Internal Server Error: Failed to fetch statistics

### Example Request

```bash
curl -X GET https://your-domain.com/api/teams/stats \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### Example Response

```json
{
  "totalUsers": 150,
  "activeUsers": 45,
  "recentUsers": 12,
  "timestamp": "2023-10-16T10:30:00.000Z"
}
```

## Error Responses

All endpoints may return error responses in the following format:

```json
{
  "message": "Error description",
  "error": "Error details"
}
```

### Common Error Codes

- `401` - Unauthorized: Authentication required or invalid session
- `404` - Not Found: Resource not found
- `500` - Internal Server Error: Server-side error occurred
