# Teams API

Teams sit between groups and individual users, enabling finer-grained collaboration.

## Endpoints

### GET `/api/teams/[id]`
Fetch detailed information about a specific team.

### GET `/api/teams/stats`
Retrieve aggregate statistics for all teams (admin only).
