# Teams API

The Teams API provides endpoints for retrieving user information and team statistics.

## Get User by ID

Retrieve detailed information about a specific user, including their posts and accounts.

### Endpoint

```
GET /api/teams/[id]
```

### Parameters

| Parameter | Type   | Required | Description                |
|-----------|--------|----------|----------------------------|
| id        | string | Yes      | The unique user identifier |

### Response

Returns a user object with the following structure:

```json
{
  "id": "string",
  "name": "string",
  "email": "string",
  "posts": [
    {
      "id": "string",
      "title": "string",
      "content": "string",
      "createdAt": "datetime"
    }
  ],
  "accounts": [
    {
      "id": "string",
      "provider": "string",
      "providerAccountId": "string"
    }
  ]
}
```

### Error Responses

- `404` - User not found
- `500` - Internal server error

### Example

```bash
curl https://your-domain.com/api/teams/user-123
```

## Get Team Statistics

Retrieve statistics about users in the system. This endpoint requires authentication.

### Endpoint

```
GET /api/teams/stats
```

### Authentication

This endpoint requires a valid session. Include your session token in the request.

### Response

Returns statistics with the following structure:

```json
{
  "totalUsers": 150,
  "activeUsers": 42,
  "recentUsers": 8,
  "timestamp": "2025-10-20T22:34:36.377Z"
}
```

### Response Fields

| Field        | Type    | Description                                    |
|--------------|---------|------------------------------------------------|
| totalUsers   | integer | Total number of users in the system            |
| activeUsers  | integer | Number of users with active sessions           |
| recentUsers  | integer | Number of users created in the last 7 days     |
| timestamp    | string  | ISO 8601 timestamp of when stats were generated|

### Error Responses

- `401` - Unauthorized (no valid session)
- `500` - Internal server error

### Example

```bash
curl https://your-domain.com/api/teams/stats \
  -H "Cookie: next-auth.session-token=YOUR_SESSION_TOKEN"
```
